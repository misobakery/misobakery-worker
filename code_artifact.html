GitHub Pages 고정 URL 배포 가이드 (3분 완성)

  1. 파일 저장: 이 코드를 index.html 이름으로 저장합니다.
  2. GitHub 업로드: GitHub에서 새 저장소(예: store-hr)를 만들고 Add file → Upload files로 index.html을 올립니다.
  3. Pages 활성화: 저장소의 Settings → Pages → Branch: main → Save를 누르면 고정 주소(https://계정.github.io/store-hr/)가 생성됩니다.
  4. Firebase 연결: Firebase 콘솔에서 무료 프로젝트 생성 → Authentication(익명 로그인 사용) 및 Firestore Database 활성화 후 위 입력칸에 웹 앱 JSON을 붙여넣고 저장하세요.
  5. 태블릿 배치: 상단의 [직원 태블릿용 URL 복사]를 눌러 매장 태블릿 주소창에 열고 홈 화면에 추가하면 완료됩니다!
